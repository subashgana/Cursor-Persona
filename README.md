# Cursor-Persona

Utilities for generating persona-isolated Adobe Express prompt test cases.

## Bird logo prompt generator

Use `tools/generate_bird_logo_prompts.py` to map
`persona_background_test_cases.json` records to Adobe Express features and create
unique prompts for the shared Bird logo task.

See `docs/bird_logo_persona_prompt_generation.md` for input requirements and
commands.
